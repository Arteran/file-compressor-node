# Node.js Compression App

Швидкий та надійний сервер для стиснення файлів на базі Node.js

---

## Опис

**Node.js Compression App** — це локальний веб-сервер, який надає простий та зручний інтерфейс для стиснення ваших файлів. Завдяки використанню вбудованих можливостей Node.js (`zlib`), програма працює швидко та ефективно. 

Проект підтримує популярні алгоритми стиснення та віддає готові архіви безпосередньо у вигляді завантаження в браузері.

## Основні можливості

- **Веб-інтерфейс**: Зручна HTML-форма для завантаження файлів (за адресою `/`).
- **Підтримка різних форматів**:
  - `gzip` (.gz)
  - `deflate` (.dfl)
  - `brotli` (.br)
- **Потокова обробка (Streams)**: Використання потоків (Streams) дозволяє обробляти великі файли без перевантаження оперативної пам'яті.
- **Надійна обробка помилок**: Автоматичне очищення ресурсів при обриві з'єднання.

## Технологічний стек

| Технологія | Опис |
| :--- | :--- |
| **Node.js** | Основне середовище виконання. |
| **http** | Вбудований модуль для створення сервера. |
| **zlib** | Вбудований модуль для стиснення (Gzip, Deflate, Brotli). |
| **formidable** | Бібліотека для парсингу `multipart/form-data` (завантаження файлів). |
| **Jest / ESLint / Prettier** | Тестування та підтримка якості коду. |

## Як запустити проект

### 1. Встановлення залежностей
Переконайтеся, що у вас встановлений Node.js. Після клонування репозиторію виконайте команду:

```bash
npm install
```

### 2. Запуск сервера
Для старту сервера виконайте:

```bash
npm start
```
Сервер буде доступний за адресою: **http://localhost:5700**

### 3. Лінтер та форматування коду
Щоб перевірити код лінтером та відформатувати його, використовуйте:
```bash
npm run lint
```
Або лише форматування:
```bash
npm run format
```

### 4. Тестування
Проект покритий тестами за допомогою Jest. Для їх запуску:
```bash
npm test
```
